## Data

- The `data/` directory contains all input datasets used by the notebooks:
  - `data/raw/`: RIPE Atlas raw measurement results (`measurement_<ID>_results.json`). Used as the primary input corpus.
  - `data/targets/`: target domain lists and metadata (e.g., `all_cdn_domains_new.json`).
  - `data/vantage_points/`: vantage/anchor metadata (e.g., `all_anchors_details.json`, `uncommon_countries_anchors.json`, `anchors_only_in_top_common_countries.json`).
  - `data/anchor_probe_info/`: anchor <-> probe mapping (`anchor_probe_info.json`).
  - `data/csv/`: CSV exports generated by analysis (may be empty until notebooks and scripts are run).
  - `data/plots/`: saved figures produced by notebooks and scripts.
  - `data/text/`: text outputs such as extracted IP lists and simple statistics.

Notes:
- Filenames under `data/raw/` follow the pattern `measurement_<ID>_results.json`, where `<ID>` is the RIPE Atlas measurement identifier described in the paper.

## Installation

It is recommended to use a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Then install the required packages:

```bash
pip install -r requirements.txt
```
You also need to follow the installation in https://github.com/SmartMonitoringSchemes/HDPHMM.jl/tree/master to use the HMM-HDP method.

## Usage

The notebooks in `notebooks/` are organized as follows:

- `ExperimentOrchestration.ipynb`: orchestrates RIPE Atlas measurements and records measurement IDs and target sets; references `data/targets/`.
- `AtlasProbes.ipynb`: explores anchors selection; uses `data/vantage_points/`.
- `DestinationIPs.ipynb`: extracts and enriches destination IPs from raw results in `data/raw/`, can produce CSV/text outputs in `data/csv/` and `data/text/`.
- `ComputeStatistics.ipynb`: computes aggregate statistics from inputs (typically `data/raw/` and enrichment outputs), writing summaries to CSV/JSON.
- `ChangePointAlgorithms.ipynb`: contains code for change-point analyses; see Installation for the external dependency link.
- `ExperimentAnalysis.ipynb`: Does simple analysis on the obtained raw data.
- `SlidePlots.ipynb`: produces presentation figures.

Placeholders: Obvious data path placeholders have been replaced to point into `data/` (e.g., anchor and anchors-details JSON files, input results dir). You may still need to provide external paths for any API credentials if you intend to re-run data collection.
